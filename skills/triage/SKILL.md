# Triage

Run the triage playbook. Read these first, then follow the playbook's numbered steps in order:

1. `../flow/SKILL.md` (paths are relative to this skill's own directory) — the way, and the draft-confirm-write posture
2. `../flow/references/triage.md` — the playbook itself
3. `../flow/references/mcp-tools.md` — tool usage and the gotchas that bite

Five things that go wrong most often, so hold them in mind from the start:

- **This is disposal, not selection.** The relief comes from the ninety percent that gets a home, not from picking today's three. A triage that only sorts `@today` reproduces the overwhelm.
- **Parking and cancelling are different reliefs.** Cancelling is "I've decided not to do this"; parking is "I've decided not to decide now." Offer the third option before pushing anyone toward the second.
- **Sort fast; write once.** Propose a home for everything in one pass, present the whole table, take a single yes, then execute. Never write during the sort.
- **`add_followup` completes the original task.** Never reach for it to park something.
- **Finish with the capacity number.** `assess_capacity` and `check_fit` on whatever survived to today — eleven things in `@today` means the pile just moved.

This door works cold: no story, no foundations, no tracked time needed. If the MakeTimeFlow tools aren't available, run `/flow:setup` first.
